# College Assignment
A assignment where we train a model by using a datasets from a kaggle webiste, where in my case I'm using a datasets of anilist

## Model used
scikit-learn
joblib
pytest
numpy

## Kaggle dataset used
[Anilist Dataset](https://www.kaggle.com/datasets/mateocoelho/anime-dataset?resource=download)

## To use
1. Go to a console command
2. type python train.py
3. then type python inference.py
4. Lastly type pytest test_model.py
if there's a warning just don't mind it
you can just type
pytest test_model.py --disable-warnings
